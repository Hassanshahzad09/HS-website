# Heritage Shapes — website

Premium printing & packaging site built with Next.js (App Router), React, TypeScript, Tailwind CSS v4 and Motion.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run images   # re-render the product visuals in /public
```

If `npm run` fails because the folder path contains `&`, start it directly:
`node node_modules/next/dist/bin/next dev`

## Where things live

| Folder | Contents |
| --- | --- |
| `app/` | Routes: home, `/products`, `/products/[slug]`, `/quote`, API stub, sitemap, robots |
| `sections/` | Home page sections, one file each, in story order (see `app/page.tsx`) |
| `components/` | Shared UI: navbar, footer, cursor, preloader, buttons, reveals, swatches |
| `products/` | Catalogue grid, product card, product detail + customiser |
| `data/products.ts` | The product catalogue. Add an entry and it appears everywhere |
| `data/site.ts` | Contact details, stats, FAQ, testimonials, portfolio, process copy |
| `lib/` | Helpers: enquiry submission, wishlist / recently-viewed storage, map projection |
| `scripts/generate-images.mjs` | Draws every product, mock-up and portfolio image |
| `public/` | `products/`, `mockups/`, `images/`, logo mark, social share image |

## Before launch

Search `data/site.ts` and `data/products.ts` for `PLACEHOLDER`:

- Domain, email, WhatsApp number and social links
- The four headline numbers
- Testimonials (sample quotes) and FAQ answers
- Minimum order quantities on each product

The portfolio projects are fictional concept brands, labelled "Concept project" on the site.

## Replacing the images

The visuals are studio-style renders generated by the script, not photographs.
To use real photography, drop a file with the same name into `public/products`,
`public/mockups` or `public/images` (WebP, roughly 1400×1050 for products).

## Connecting a backend

The quote builder, contact form and newsletter all call `submitEnquiry()` in
`lib/enquiry.ts`, which posts to `app/api/enquiry/route.ts`. That route only
validates and returns a reference today; forward the payload to email, a CRM or
a database there. Uploaded artwork currently sends the file name only.

## Motion and accessibility

Animations respect the operating system's "reduce motion" setting: with it on,
pinned scroll scenes fall back to simpler layouts and transforms are skipped.
